# Banka Sistem Otomasyonu

Basit bir **Flask (Python)** ve **React (JavaScript)** tabanlı banka otomasyon sistemidir.

## Özellikler

- Kullanıcı girişi (TC ve şifre ile)
- Müşteri bazlı hesap yönetimi
- Vadesiz ve vadeli hesap ayrımı
- Para yatırma, çekme ve borç ödeme işlemleri
- Gerçek zamanlı toplam bakiye ve işlem geçmişi

## Teknolojiler

- Backend: Flask + JSON tabanlı veri yönetimi
- Frontend: React + Axios
- API Test: Postman

## Kurulum

1. Backend çalıştır:

- cd backend
- python api.py

2. Frontend çalıştır;

- cd frontend
- npm install
- npm start
